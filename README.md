# La République c'est quoi ?

Première ébauche d'analyse des compte-rendus de débats à l'Assemblée nationale (2017-2024) faisant mention de la famille du mot "République".  
Collaboration entre [Léo Mignot](https://www.centreemiledurkheim.fr/notre-equipe/leo-mignot/) et [Matthias Levalet](https://www.centreemiledurkheim.fr/notre-equipe/matthias-levalet/) sur l'objet de la thèse de ce dernier. 
Collaboration commencée dans le cadre de [SICSS-Paris 2025](https://sicss.io/2025/paris/).
Pour plus d'informations sur les données utilisées et les choix effectués, voir les .md du dossier exploration.
